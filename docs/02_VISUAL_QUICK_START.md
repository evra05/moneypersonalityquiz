## 🎯 Common Tasks Quick Guide

### Task: Start Development Server

```bash
cd moneypersonalityquiz
npm start
# Open: http://localhost:8080
```

### Task: View Admin Panel

```bash
# Make sure server is running (npm start)
# Open browser: http://localhost:8080/admin-panel.html
# Login: admin2024 / MoneyTest@2024!
```

### Task: Deploy to Production

```bash
# Option 1: GitHub Pages
npm run deploy

# Option 2: Firebase Hosting
firebase deploy
```

### Task: Add New Question

```javascript
// 1. Open: src/js/questions.js
// 2. Add question object:
{
    questionNo: 21,
    question: "Your question here",
    personalityType: "Saver"  // or other type
}
// 3. Update constants.js (TOTAL_QUESTIONS)
// 4. Test the quiz
```

### Task: Export Quiz Results

```bash
# 1. Open admin panel
# 2. Login
# 3. Click "Export" button
# 4. Choose format (CSV/JSON)
# 5. Download file
```

## ⚡ Quick Commands Reference

```bash
# Development
npm install          # Install dependencies
npm start            # Start server (port 8080)
npm run dev          # Start server (port 3000)

# Deployment
npm run deploy       # Push to GitHub
bash deploy.sh       # Deploy script
firebase deploy      # Deploy to Firebase

# Git
git status           # Check status
git add .            # Stage changes
git commit -m "..."  # Commit
git push             # Push to remote

# Firebase
firebase login       # Login
firebase init        # Initialize
firebase deploy      # Deploy
```
